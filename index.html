System Design

How PostAI Works

A five-stage pipeline that turns a raw postal address into an explainable delivery office recommendation.

5-Stage Analysis Pipeline

1
Stage 1
Address Input
The user provides a raw postal address (text) or uploads an image of an address label. The system accepts Indian address formats including structured and unstructured text.
2
Stage 2
Address Parsing
PostAI's parser extracts structured components: house/unit number, street name, area/locality, city, district, state, and PIN code using pattern matching and known entity dictionaries.
3
Stage 3
PIN & Location Validation
The extracted PIN is validated for format, regional zone, and consistency with the stated area. Mismatches between area names and PIN code service areas are flagged for review.
4
Stage 4
Geospatial Post Office Matching
The address is geocoded via the Nominatim / OpenStreetMap API (with a local area-lookup fallback). The Haversine formula calculates the real-world distance from the destination to every post office in the dataset.
5
Stage 5
Explainable Recommendation
Each candidate post office receives a weighted composite score. The highest-scoring office is recommended with a confidence percentage and a plain-language explanation of every factor that influenced the decision.

API Integration

No API Key Required
Geocoding
Nominatim / OpenStreetMap
Free geocoding API. Converts postal addresses to latitude/longitude. No API key required. Rate-limited to 1 request/sec.
Mapping
Leaflet + OpenStreetMap Tiles
Open-source interactive maps with OpenStreetMap tile data. No paid subscription. Markers and route lines rendered client-side.
Fallback
Local Area Coordinate Lookup
If Nominatim is unavailable, the system uses a local table of area → coordinates for all major Chennai localities. Works offline.

Problem Description

Customers and postal operators face significant challenges in identifying the correct delivery post office when postal addresses contain incorrect, incomplete, ambiguous, or mismatched address and PIN code information. This leads to delays, misrouting, and inefficiencies in the postal delivery system. The goal is to develop an AI-powered system that can intelligently analyze addresses, validate PIN codes against geographic locations, identify the most appropriate delivery post office, and flag potential inconsistencies for human review.

PostAI's Approach

🔍
Structured Address Parsing
Regex and keyword-based extraction of all address components without requiring a trained ML model — fast, interpretable, and reliable.
🌐
Open Geospatial Stack
Nominatim + OpenStreetMap + Leaflet provide a complete, free, open-source geospatial pipeline with no vendor lock-in or API cost.
📊
Transparent Scoring
Every recommendation includes the individual component scores and the reasons behind the final decision — fully explainable to postal staff.
